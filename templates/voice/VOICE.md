## Before posting
- [ ] The first line holds the point. A reader who stops there still learns something.
- [ ] One idea per post, one ask.
- [ ] Every claim has a number, a link or a screenshot. No adjectives where a number fits.
- [ ] The text is written in its language from the brief, not translated.
- [ ] Words match the "words we use" list in the Brief.
- [ ] No private data, no unreleased feature, no model-provider name in store text.
- [ ] Sentences are at most 25 words. Run Vale (English) or Glavred (Russian) if you use them.
- [ ] Read it aloud once. Cut every sentence you stumble on.
