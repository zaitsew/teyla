# Index

One line per page: title, one-sentence summary, last-verified date. Kept in
sync by the `wiki-pass` skill — a page is not "in" the wiki until it has a line
here, and `teyla wiki lint` fails if a page and an index line disagree.

Line format (one per page, alphabetical by title):

    - [<title>](pages/<slug>.md) — <one-sentence summary> (last verified: <YYYY-MM-DD>)
