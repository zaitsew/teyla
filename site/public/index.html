Four problems it takes off your hands

Spend you cannot see

Long sessions re-read their whole context every turn. Teyla finds them, compacts earlier and runs subagents on cheaper models.

teyla apply O1

Questions nobody reads

A session ends on a question and the work stops. Every open question sits on one screen, oldest first, with a link back to the session.

teyla asks

Agents that forget

A correction made in Claude Code is unknown to Codex. One POLICY.md is linked into Claude Code, Codex, Grok, Cursor and Hermes.

teyla policy sync

A Mac that falls over

Parallel agents swap the Mac until it hangs or panics. Teyla admits one heavy build or simulator at a time and holds new ones under memory pressure.

teyla load

Tick the packs you need. Teyla turns on only those, and names another one when its problem shows up.

  • Token cost. Long sessions re-read their whole context every turn. Teyla compacts earlier and runs subagents on cheaper models.
  • Machine guard. Parallel agents swap the Mac until it hangs. Teyla admits one heavy build or simulator at a time.
  • Disk cleanup. DerivedData, worktrees and simulators fill the disk. Teyla sweeps temp build output every hour.
  • Questions and ideas. A session ends on a question and nobody reads it. Teyla keeps every open question on one screen.
  • One policy. A correction made in Claude Code is unknown to Codex. One POLICY.md is linked into every agent.
  • Morning check. A broken hook goes unseen for weeks. Teyla runs a daily check and a six-line weekly digest.
  • Security. A secret ends up in a public repo. Teyla refuses a publish that carries one and audits dependencies.
  • UX and UI. Screens ship with noise. Teyla checks UI code against one standard and judges two screens.
  • Ship and test. A build is uploaded, but no tester can install it. Teyla tracks each platform and unreviewed merges.
  • Writing. Replies and READMEs are long and padded. Teyla measures filler and checks drafts against a voice chart.

Nothing about your sessions leaves your Mac unless you turn it on

  • No server, no account, no telemetry. Every network call is listed.
  • Each change asks first and names the file, the saving and the way back. teyla undo O1 puts back the setting.
  • Open source under Apache-2.0. This site sets no cookies and loads nothing from another host.

Where it runs

  • Command line and teyla web. Available now. The web page runs on 127.0.0.1, on your Mac.
  • Mac app. Build it from source today, with macOS 15 and Xcode. See how.
  • iPhone app and Mac App Store. Not on sale yet. The iPhone app reads a signed folder in your own iCloud Drive; there is no Teyla server.

Install by hand

You need a Mac and uv. The first command installs Teyla. The second shows the diagnosis, the checklist of packs, then each change: yes, no or explain.

uv tool install --python 3.12 git+https://github.com/zaitsew/teyla
teyla start

To look without installing, run this. It changes no setting of your tools and keeps its counts in ~/.teyla.

uvx --python 3.12 --from git+https://github.com/zaitsew/teyla teyla start
