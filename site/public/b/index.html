Nothing about your sessions leaves your Mac unless you turn it on

  • No server, no account, no telemetry. Every network call is listed.
  • Each change asks first and names the file, the saving and the way back. teyla undo O1 puts back the setting.
  • Open source under Apache-2.0. This site sets no cookies and loads nothing from another host.

Where it runs

  • Command line and teyla web. Available now. The web page runs on 127.0.0.1, on your Mac.
  • Mac app. Build it from source today, with macOS 15 and Xcode. See how.
  • iPhone app and Mac App Store. Not on sale yet. The iPhone app reads a signed folder in your own iCloud Drive; there is no Teyla server.

Install by hand

You need a Mac and uv. The first command installs Teyla. The second shows the diagnosis, the checklist of packs, then each change: yes, no or explain.

uv tool install --python 3.12 git+https://github.com/zaitsew/teyla
teyla start

To look without installing, run this. It changes no setting of your tools and keeps its counts in ~/.teyla.

uvx --python 3.12 --from git+https://github.com/zaitsew/teyla teyla start
